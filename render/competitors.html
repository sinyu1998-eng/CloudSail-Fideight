护城河Four moats competitors can't copy

1 · 数据网络效应

Data network effect

每次验货沉淀为链上履约履历 → 履历越好押金费率越低 → 转移成本随时间复利。可以抄代码，抄不走一条从 2025 年开始累积的信誉账本。

2 · 递归自改进

Recursive self-improvement

争议数据自动回流调优风控参数（见原型仿真），欺诈模型越用越准；新进入者的起点永远是第 0 代。

3 · 硬件入口

Hardware entry

云帆 AI 眼镜 = 行走的验货器。第一公里证据采集已被我们占住，体验差距无法靠 API 追平。

4 · 合规即功能

Compliance-as-a-feature

出口管制热点自动拒单并留痕（如俄+英伟达场景）——对买方是安全，对监管是透明，是卖点不是负担。
