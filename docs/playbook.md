## 0. 定位宣言 Positioning

**我们不是代运营，也不是数据工具。我们卖的是"跨境交易的可信履约"。**
收入来自把「验货 → 存证 → 托管 → 结算」这条链打包成可订阅、可按需调用的服务；长期壁垒来自协议层（自己写的合约），现金流来自服务层（人+Agent 交付）。

*We don't run stores or sell dashboards. We sell trustworthy fulfillment for cross-border trade. Revenue comes from packaging inspection → attestation → escrow → settlement as services; the moat is the protocol layer; the cash flow is the service layer.*

**一句话分工：协议层必须是我们的（自建合约）， commodity 标准一律接入最好的。**
*The protocol layer must be ours; everything commoditized gets integrated with the best provider.*

## 3. 团队分工 Team structure

### 3.1 招聘原则 Hiring principle（AI-Native 版）

> **先问：这件事 AI 能不能做 80%？能做就先不招人。** 招人只在三个点：①物理到场 ②法律责任签字 ③关系与信任建立。
> *Ask first: can the agent do 80% of it? If yes, don't hire yet. Hire only at three points: physical presence, legal signature, relationship building.*

## 4. 合约决策：自建 vs 接入 Contract decisions

**原则：凡是别人已经做成行业标准的，一律接入；凡是决定我们收入与护城河的，必须自建。**
*Integrate what's standardized; own what determines our margin and moat.*

| 能力 | 决策 | 选择 | 理由 |
|---|---|---|---|
| 链上存证 Attestation | **接入** | EAS（Ethereum Attestation Service） | 已是事实标准，可让任何人独立核验 |
| 争议仲裁 Arbitration | **接入** | Kleros | 自建仲裁没有可信陪审团，也没有 network effect |
| 账户抽象/钱包 AA | **接入** | ERC-4337 + Safe 生态 | 用户免助记词是体验问题，非壁垒 |
| 稳定币结算 Stablecoin | **接入** | USDC | 合规性与流动性都不容自建 |
| Agent 微支付 Agent payments | **接入/兼容** | x402 协议 | 顺应 Tether/Coinbase 推动的标准（见 AIsa 报告） |
| 法币收单 Fiat acquiring | **接入** | Airwallex | 牌照与 130+ 币种不是我们的战场 |
| 合规名单 Sourcing | **接入 + 自建规则层** | 制裁名单源 + 自写规则引擎 | 数据买/接，判断逻辑是壁垒 |
| **里程碑托管 Escrow** | **⭐ 自建** | MilestoneEscrow.sol | 直接决定收入（0.3–0.8%）与结算控制权——**这是公司的心脏，不能外包** |
| **声誉与自调 Reputation/RSI** | **⭐ 自建** | ReputationLedger + EpochGovernor | 参数自调是数据飞轮，仿真已证信任成本 −86% |
| **物理证据网络 Capture network** | **⭐ 自建** | CloudSail 眼镜 + PWA + 验货方市场 | 别人没有"货在面前的 10 分钟" |
| 账本核算 Ledger | 自建轻层 | 复式分录合约 + 导出 | 与托管强耦合，不做厚 ERP |

**自建三条红线（同时满足才动手）**：① 直接决定毛利 ② 没有成熟标准可接 ③ 构成长期护城河。缺一即接入。
*Build only if all three hold: it drives margin, no standard exists, and it compounds into a moat.*

## 6. 风险红线 Red lines

- **资金线隔离**：法币（Airwallex）与链上（USDC）分账，绝不互相填充流动性
- **合规一票否决**：俄罗斯/白俄罗斯/受管制 GPU 订单自动拒单——拒单是产品特性，不是缺陷
- **不承诺收益**：所有对外材料不得出现"保证转化""稳赚"字样
- **数据许可**：只接有授权的数据源；AI 输出沿用"无数据即写无数据"的家规
- **单人决策风险**：托管的私钥/升级权限必须多签，任何单人不得单独放款
