架构：一切皆插件Architecture — everything is a plugin

连接器层

Connectors

每个平台一个插件，统一吐出归一化 Order（买家/金额/币种/SKU/里程碑）。新增平台 = 新增一个文件。

One plugin per platform emitting normalized Orders. New platform = one new file.

状态机层

State machine

九态履约状态机（见专栏首篇），每次转移触发存证与放款事件。

Nine-state fulfillment machine; every transition emits attestation and release events.

工具层

MCP tools

所有能力暴露为 MCP 工具，任何兼容客户端（含 dsh）可直接调用。LLM 只理解，不碰钱。

Every capability is an MCP tool, callable from any compatible client. The LLM understands; it never moves money.
