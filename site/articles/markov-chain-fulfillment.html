马尔可夫链与一票货的九态人生

Markov Chains & the Nine Lives of a Shipment

作者：Qianru（云帆出海 CloudSail）· 专栏第 1 篇

一、为什么跨境履约适合用马尔可夫链Why fulfillment fits a Markov chain

一票跨境货物的一生，可以被离散成有限个状态；而它下一步去哪里，几乎只取决于它现在在哪，而不是它过去走过哪条路。这正是马尔可夫性（Markov property）：

P(X_{t+1} = j | X_t = i, X_{t-1}, …, X_0) = P(X_{t+1} = j | X_t = i)

The next state of a shipment depends almost entirely on its current state, not its path history — that is exactly the Markov property.

注意：这是工程近似，不是物理定律。真实世界里"被退过一次款的订单更容易再出问题"这种记忆效应确实存在——我们用吸收态细分（把"争议"拆成"首次争议/再次争议"）来消化它，这是标准的补救手法。

二、九个状态The nine states

S1 已下单 Ordered S2 合规通过 Cleared S3 已托管 Funded S4 验货存证 Attested S5 已发货 Shipped S6 已签收 Received S7 结清 Settled S8 争议 Disputed S9 坏账 Defaulted

其中 S7 与 S9 是吸收态（进去就出不来）；S8 是暂态，可以回到 S4–S6 的任何一步，也可以跌进 S9。

S7 and S9 are absorbing states; S8 is transient — it can bounce back to S4–S6 or fall into S9.

三、转移矩阵与它的业务读法The transition matrix, read as a business

S2 S3 S4 S5 S6 S7 S8 S9 S1 [ .95, 0, 0, 0, 0, 0, .05, 0] S2 [ 0, .98, 0, 0, 0, 0, .02, 0] S3 [ 0, 0, .96, 0, 0, 0, .04, 0] S4 [ 0, 0, 0, .97, 0, 0, .03, 0] S5 [ 0, 0, 0, 0, .94, 0, .06, 0] S6 [ 0, 0, 0, 0, 0, .97, .03, 0] S8 [ 0, 0, .30, .20, .15, 0, 0, .35]

读法示例：从"已发货 S5"出发，6% 的票会进争议。而争议票里有 35% 最终跌进坏账 S9——所以整条链最贵的边是 S8→S9。

四、吸收概率：钱到底亏在哪一步Absorption probabilities: where money is actually lost

把矩阵分块成 P = [Q R; 0 I]，则基本矩阵 N = (I − Q)⁻¹，从状态 i 出发最终被 S9（坏账）吸收的概率：

B = N · R，坏账率 b_i = B[i, S9]

用上面的示意矩阵粗算：从 S5 出发的坏账概率 ≈ 0.06 × 0.35 ≈ 2.1%；从 S3 出发 ≈ 0.04×0.35 + 后续各步累乘 ≈ 3.4%。这告诉我们两件事：

1) 保险和仲裁资源应该重点铺在 S5→S8 这条边上（发货到签收之间），而不是均匀撒。2) 每降低 1 个百分点的 S8→S9 转化，全程坏账率近似线性改善——这就是为什么我们把"争议三分钟证据包"当作核心指标。

Insurance and arbitration belong on the S5→S8 edge, not spread evenly. Every point shaved off S8→S9 improves end-to-end default rate roughly linearly — hence our "evidence pack in three minutes" KPI.

五、关键一步：转移矩阵不是拍脑袋，是观测出来的The matrix is observed, not guessed

传统的贸易平台拿不到可信的状态数据——验货报告是 PDF，可以改；聊天记录在 WhatsApp，可以删。我们的链路里，每一次状态转移都是一笔 EAS 链上存证：验货通过有哈希、发货有物流单据哈希、签收有签名。也就是说，转移矩阵 P 的每一个元素都是可审计的频次统计：

p̂_ij = N_ij / Σ_k N_ik，其中 N_ij = 链上观测到的 i→j 转移次数

这就是"链上作证"超越"存个证"的地方：存证是防守（出事了有证据），而矩阵是进攻（没出事就知道该在哪一步设防）。

Attestation is defense (evidence when things go wrong); the matrix is offense (knowing where to fortify before they do).

六、诚实声明Honest caveats

· 上面的数字是结构示意，不是实测——实测需要足够多的链上转移样本，这正是我们要做试点的原因。
· 马尔可夫性在"重复争议"上会被打破，我们用状态细分补偿；更精细的模型（半马尔可夫、生存分析）留给连载。
· 矩阵会随品类、航线、季节漂移，需要滚动窗口重估——这会成为驾驶舱里的一张实时表。
